# Task 3: Deep-Dive Analysis & Interactive Dashboarding

## Objective

To perform a deep-dive analysis of sales data and build an interactive dashboard that provides actionable business insights.

## Core KPIs

* Total Sales
* Average Sales
* Top Product
* Top Region

## Deep-Dive Analysis

A segmentation analysis was performed to identify:

* Best-performing products
* Regional sales trends
* Sales distribution patterns

## Key Findings

* Laptop generated the highest sales revenue.
* West region achieved the highest sales performance.
* Sales distribution was relatively consistent.
* No major outliers were detected.

## Dashboard Development

An interactive Power BI dashboard was developed featuring:

* KPI Cards
* Product Filters
* Sales Charts
* Region Analysis
* Interactive Visualizations

## Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Power BI

## Business Impact

The dashboard enables stakeholders to monitor sales performance, identify top-performing products, and make data-driven business decisions.
